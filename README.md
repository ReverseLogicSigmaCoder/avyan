# AVYAN — Automated DevSecOps & Security Pipeline Engine

SUDARSHAN Engine is a lightweight, automated Static Application Security Testing (SAST) pipeline designed to run within GitHub Actions.

## ⚡ Features
* Automated Secret & Token Detection
* CI/CD GitHub Actions Integration
* Dynamic HTML & Audit Report Generation

## 🚀 Quick Setup Guide
Add `.github/workflows/sudarshan_cron.yml` to your target repository to automatically run pre-commit scans.
